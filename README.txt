RIYANJALI FOODS / BOKF WEBSITE CONCEPT
======================================

Open index.html in a browser to preview the website.

Files:
- index.html  : main website
- styles.css  : complete responsive design
- script.js   : mobile menu + scroll animation

Important before selling/publishing:
1. Replace placeholder/editorial food photography with official Riyanjali Foods/BOKF product photos supplied by the business.
2. Confirm the exact business address, phone/WhatsApp, email, operating hours and social profiles before adding them.
3. Replace Amazon/Meesho search links with the business's exact official product/store URLs wherever possible.
4. This concept intentionally does NOT contain its own checkout. Visitors discover products here and buy through marketplaces.

The current version uses externally hosted images and Google Fonts, so internet access is required for the full visual presentation.
